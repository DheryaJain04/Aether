# EJS Frontend Archive

This folder archives the original server-side rendered (SSR) EJS frontend components, views, styles, and routes of Aether.

As of this migration, the primary frontend for Aether is the modern React single-page application located in `/client`.

### Archived Contents:
- `views/`: EJS templates (`home.ejs`, `search.ejs`, `paper.ejs`, `saved.ejs`, including the enhanced ranking UI versions).
- `routes/`: EJS SSR route handlers (`home.js`, `search.js`, `saved.js`).
- `controllers/`: `homeController.js`.
- `public-css/`: CSS stylesheets used by the EJS views.

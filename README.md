# Aether

Aether is an AI-powered research assistant designed to simplify academic literature discovery and analysis. It combines semantic search, intelligent ranking, large language models, and Retrieval-Augmented Generation (RAG) to help researchers find, understand, and interact with research papers more efficiently.

> **Status:** Currently under active development.

---

## Features

- Semantic research paper search using the OpenAlex API
- Custom Aether Ranking Engine with multiple ranking modes
- AI-generated paper summaries
- RAG-powered research chatbot
- Interactive paper details page
- Open Access detection
- DOI support
- Research paper metadata and citation information
- Modern responsive UI
- MongoDB integration for future personalization

## Installation

### Clone the repository

```bash
git clone https://github.com/DheryaJain04/Aether.git
```

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```
